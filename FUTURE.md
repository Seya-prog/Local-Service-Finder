# 🔮 FUTURE.md — Features Cut Due to Time

These features were considered but cut from the 5-day capstone timeline:

## Planned for Future Development

1. **Admin Dashboard** — A super-admin role to manage all users, services, and bookings
2. **Real Database** — PostgreSQL/MySQL with Prisma/Drizzle ORM instead of mock arrays
3. **Image Upload** — Profile picture upload for providers with cloud storage
4. **Real-time Notifications** — WebSocket-based booking notifications
5. **Rating & Review System** — Customers can rate and review after service completion
6. **Payment Integration** — Stripe/Chapa integration for booking payments
7. **Geolocation & Maps** — Map view for nearby providers using Google Maps API
8. **Social Login** — OAuth with Google, GitHub, etc.
9. **Email Verification** — Email confirmation on signup
10. **Multi-language Support** — Full Amharic/English internationalization
11. **Advanced Search** — Autocomplete, price range filters, availability filters
12. **Provider Analytics** — Dashboard charts for booking trends and revenue
13. **Mobile App** — React Native version for iOS/Android

---

*These features are achievable with the current architecture and can be incrementally added.*
